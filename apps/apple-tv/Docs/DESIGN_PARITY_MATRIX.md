# Web-to-tvOS design parity matrix

Reference inspected at task base `744491eeffeb9f64eead66397c8df59466f8b16e`: React entry `apps/tv/src/main.tsx`, product view `apps/tv/src/App.tsx`, catalogue adapter `apps/tv/src/catalogue.ts`, media URL policy `apps/tv/src/media.ts`, and visual source `apps/tv/src/styles.css`. Existing reference files remain unchanged.

| Web experience                               | Native tvOS counterpart         | Data source                              | Shared identity                                                             | Television adaptation                                                                              | Status                           |
| -------------------------------------------- | ------------------------------- | ---------------------------------------- | --------------------------------------------------------------------------- | -------------------------------------------------------------------------------------------------- | -------------------------------- |
| Protected Cloudflare Access email/code entry | Device activation               | Isolated gateway authorization endpoints | Restrained dark branded entry, same product language                        | Code + QR approved on another device; no web view or text-heavy TV login                           | Implemented                      |
| Profile selection                            | Authenticated household session | Scoped session identity                  | Centered wordmark, gold/cyan accents                                        | A single approved TV session avoids inventing profile data not exposed by the gateway              | Intentionally adapted            |
| Home hero and primary actions                | Home hero                       | Authenticated `/v1/catalog`              | Edge-to-edge backdrop, dark gradients, white hierarchy, primary Play action | Larger safe-area margins and deterministic focus order                                             | Implemented                      |
| Horizontal collection/movie rows             | Focusable media shelves         | Catalog categories and ordering          | Poster crop, rounded cards, shadows, category titles                        | Native Siri Remote focus scale/halo and horizontal shelf motion                                    | Implemented                      |
| Left icon navigation rail                    | Persistent tvOS sidebar         | Local navigation state                   | Near-black/navy rail, matching labels and icon language                     | Wider focus targets and native Menu/Back semantics                                                 | Implemented                      |
| Search/discovery                             | Search screen                   | In-memory authenticated catalog          | Same cards, empty/loading/error treatments                                  | Focus-safe search field and TV keyboard                                                            | Implemented                      |
| Collection browsing                          | Collections screen              | Fixed catalog category order             | Same collection grouping and imagery treatment                              | Grid/shelves sized for 1080p and 4K viewing distance                                               | Implemented                      |
| Movie detail overlay                         | Media detail screen             | Selected catalog item                    | Backdrop, title, metadata, description, gradient overlay, Play              | Dedicated screen with predictable Back action; no hover-only information                           | Implemented                      |
| Ambient detail preview                       | Muted native detail preview     | Authenticated playback service           | Same one-second delay, crop, gradients, and detail hierarchy                 | AVPlayer preview is muted, cancelled when leaving, and disabled when Reduce Motion is enabled       | Implemented                      |
| Web video player                             | AVKit player                    | Authenticated playback URL               | Branded handoff and matching title context                                  | Native Siri Remote play/pause, ±10-second seeking, scrubber, audio and fullscreen controls         | Implemented                      |
| Loading/error/empty states                   | Shared SwiftUI state components | App model                                | Same dark surfaces, muted copy, cyan/gold emphasis                          | Large readable copy, one obvious focused recovery action                                           | Implemented                      |
| Settings/account                             | Settings screen                 | Keychain session/config state            | Same typography and surfaces                                                | Sign-out and privacy/support diagnostics only; debug endpoint details excluded from Release        | Implemented                      |

The exact web font files are not bundled in the reference repository, so tvOS uses Apple system typography for legibility while preserving size, weight, spacing, and hierarchy. Final brand icon/top-shelf artwork and captured screens require owner visual approval before submission.
