# Age rating checklist

Do not select an age rating from this template alone. The current repository does not establish the content of every production family video, so the rights holder must watch/review the catalog and answer Apple’s current questionnaire.

## App functionality evidence

Prepared **No/None** only if the release remains as implemented:

- Unrestricted web access: no web browser or arbitrary URL navigation.
- User-generated-content posting/public sharing: none.
- Messaging/chat: none.
- Gambling, loot boxes, contests, or simulated gambling: none.
- In-app purchases/subscriptions: none.
- Advertising: none.
- Location sharing: none.

## Catalog content requiring owner review

For every title visible to App Review and every production account, record frequency/intensity for Apple’s current categories, including:

- profanity or crude humor;
- mature/suggestive themes;
- horror/fear;
- alcohol, tobacco, or drugs;
- medical/treatment content;
- cartoon/fantasy or realistic violence;
- sexual content or nudity;
- guns/weapons;
- sensitive real-world or historical events.

Private/family provenance does not exempt catalog content from rating. If accounts can expose different catalogs, rate for the highest content a user can obtain in the submitted app. Preserve the completed evidence outside source control and revisit it whenever content changes.
